description: Fetch a cited UX criteria pack for a Situation Card.
---

Call `Open-UX:audit` with `jobs=` / `guideline_ids`. `jobs=` is a stratified Card sample; `query` is optional attention. A helper `python3 scripts/audit.py --jobs <card_id>` is available if useful. Example: `/audit design_a_form`. Do not send a file.
