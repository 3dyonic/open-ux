# Cite

Thin lookup. Use when the user wants a shared rule, not a compose or review job.

- `Open-UX:search_guidelines` — query / `jobs` / lane. Index only.
- `Open-UX:get_guideline` — one id. Full cited body.
- `Open-UX:list_guidelines` — paged index. Never dump the whole catalog as the default.

If you already have a Card, prefer `Open-UX:audit` with `jobs=<card_id>` over browsing. Reuse catalog wording. Do not invent ids.
