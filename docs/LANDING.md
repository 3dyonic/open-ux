## How it works (3 steps)

1. **Connect** — install the Claude client (or any MCP client) and paste your key.
2. **List / get** — browse the shared catalog; every rule carries a citation.
3. **Audit** — send UI (html / jsx / description); get pass, fail, or incomplete with the rule id — not a guess.

## What's in v1
